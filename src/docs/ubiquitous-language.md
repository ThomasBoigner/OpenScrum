# Ubiquitous language

## Management domain

| Word    | Meaning                                            |
|---------|----------------------------------------------------|
| Manager | Managing company and projects                      |
| User    | Works in projects, can only manage his own account |
| Project | Project the company works on                       |

## Scrum domain

| Word                 | Meaning                                                                                        |
|----------------------|------------------------------------------------------------------------------------------------|
| Project              | Scrum project that gets managed                                                                |
| Product owner        | Scrum role that manages the product                                                            |
| Scrum master         | Scrum role that makes sure that the scrum rules are applied correctly                          |
| Developer            | Developers doing the work                                                                      |
| Scrum team           | Team consisting of the product owner, scrum master and all the developers                      |
| Product backlog      | List of backlog items that resemble future improvements to the product                         |
| Product backlog item | Item in the product backlog that can be commited to a sprint                                   |
| Sprint               | Heartbeat of the project in which value is being created                                       | 
| Sprint planning      | Activity in which the sprint backlog is being creaated and the next sprint is being discussed  |
| Sprint backlog       | List of backlog items that should be completed in the sprint                                   |
| Sprint backlog item  | Item in the sprint backlog which is being activlely worked on                                  |
| Daily                | Daily meeting in the development team in which the status of the developers is being discussed |
| Sprint review        | Presentation to show of progress and gather feedback from Stakeholder for eventual next steps  |
| Sprint retrospective | Development team discusses how the delveopment process could be improved                       |
