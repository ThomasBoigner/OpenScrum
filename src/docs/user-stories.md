# User stories 

1. As a manager I want to register users, so that I can give them access to the system. 
2. As a manager I want to remove users, so that I can remove their access to the system.
3. As a user I want to update my user data, so that I can provide up-to-date data.
4. As a manager I want to create a project, so that I can track the work that is being done.
5. As a product owner or scrum master I want to configure the project, so that I can define the way of working.
6. As a product owner I want to define the product backlog, so that I can list possible improvements.
7. As a scrum team I want to hold a sprint planning, so that I can organize a sprint.
8. As a product owner I want to cancel a sprint, so that I can stop a sprint that will not produce any value.
9. As a developer I want to hold a daily meeting, so that I can synchronize me work with the other developers.
10. As a developer I want to mark a sprint backlog item as done, so that I can track the progress of the sprint.
11. As a scrum team I want to hold a sprint review meeting, so that I can inform stakeholders about the progress and get feedback.
12. As a scrum team I want to hold a sprint retrospective, so that I can improve my way of working.
